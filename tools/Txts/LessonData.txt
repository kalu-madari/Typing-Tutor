Lesson 1 Name
Using Ten Fingers

Lesson 1 Data
अब सभी दसों उंगलियों का सही उपयोग करें। हर कुंजी के लिए निर्धारित उंगली का प्रयोग करें और स्क्रीन पर ध्यान रखें।


Lesson 2 Name
Increase Speed

Lesson 2 Data
धीरे-धीरे अपनी टाइपिंग गति बढ़ाएँ। जल्दबाज़ी न करें। पहले सही टाइप करें, फिर हर अभ्यास के साथ गति बढ़ाएँ।


Lesson 3 Name
Daily Practice

Lesson 3 Data
प्रतिदिन थोड़ा अभ्यास करें। नियमित अभ्यास आपकी उंगलियों को मजबूत बनाएगा और टाइपिंग पहले से अधिक आसान होगी।


Lesson 4 Name
Don't Look Down

Lesson 4 Data
टाइप करते समय कीबोर्ड की ओर न देखें। अपनी नजर स्क्रीन पर रखें और उंगलियों को सही कुंजियाँ खोजने दें।


Lesson 5 Name
Watch the Screen

Lesson 5 Data
हमेशा स्क्रीन पर ध्यान रखें। हर शब्द ध्यान से पढ़ें और बिना घबराए सही क्रम में टाइप करने का प्रयास करें।


Lesson 6 Name
Build Accuracy

Lesson 6 Data
तेज़ टाइप करने से पहले सही टाइप करना सीखें। कम गलतियाँ आपकी गति और आत्मविश्वास दोनों को बढ़ाएँगी।


Lesson 7 Name
Stay Relaxed

Lesson 7 Data
टाइप करते समय अपने हाथ और कंधे आराम में रखें। तनाव कम होगा और लंबे समय तक आसानी से अभ्यास करेंगे।


Lesson 8 Name
Smooth Rhythm

Lesson 8 Data
हर अक्षर को समान गति से टाइप करें। अच्छी लय आपकी टाइपिंग को अधिक तेज़ और सटीक बनाएगी।


Lesson 9 Name
Trust Your Fingers

Lesson 9 Data
अपनी उंगलियों पर भरोसा रखें। बार-बार कीबोर्ड देखने की आदत छोड़ें और लगातार अभ्यास करते रहें।


Lesson 10 Name
Correct Mistakes

Lesson 10 Data
गलती होने पर घबराएँ नहीं। उसे सुधारें, कारण समझें और अगली बार वही गलती दोबारा न दोहराएँ।


Lesson 11 Name
Keep Practicing

Lesson 11 Data
हर नया अभ्यास आपको बेहतर बनाएगा। लगातार मेहनत से आपकी गति, सटीकता और आत्मविश्वास तीनों बढ़ेंगे।


Lesson 12 Name
Focus Better

Lesson 12 Data
अभ्यास करते समय पूरा ध्यान केवल टाइपिंग पर रखें। एकाग्रता से गलतियाँ कम होंगी और सीखना आसान होगा।


Lesson 13 Name
Maintain Position

Lesson 13 Data
हर अभ्यास के बाद अपनी उंगलियों को होम रो पर वापस लाएँ। यही अच्छी टाइपिंग की सबसे महत्वपूर्ण आदत है।


Lesson 14 Name
Control Your Speed

Lesson 14 Data
अपनी गति पर नियंत्रण रखें। बहुत तेज़ टाइप करने की बजाय लगातार सही टाइप करने की कोशिश करें।


Lesson 15 Name
Read Before Typing

Lesson 15 Data
टाइप शुरू करने से पहले पूरे शब्द को पढ़ें। इससे गलतियाँ कम होंगी और टाइपिंग अधिक सहज लगेगी।


Lesson 16 Name
Use Every Finger

Lesson 16 Data
किसी एक उंगली पर निर्भर न रहें। सभी उंगलियों का संतुलित उपयोग आपकी क्षमता को बेहतर बनाएगा।


Lesson 17 Name
Stay Consistent

Lesson 17 Data
हर दिन समान समय तक अभ्यास करें। नियमितता आपकी टाइपिंग को लगातार बेहतर और अधिक भरोसेमंद बनाएगी।


Lesson 18 Name
Practice Carefully

Lesson 18 Data
हर अक्षर को ध्यान से टाइप करें। छोटी गलतियों पर भी ध्यान दें और उन्हें तुरंत सुधारने की आदत बनाएँ।


Lesson 19 Name
Improve Control

Lesson 19 Data
अपनी उंगलियों की हर हरकत पर नियंत्रण रखें। सही नियंत्रण से गति और सटीकता दोनों बेहतर होंगी।


Lesson 20 Name
Never Give Up

Lesson 20 Data
शुरुआत में कठिनाई होना सामान्य है। धैर्य रखें, अभ्यास जारी रखें और अपनी प्रगति पर विश्वास बनाए रखें।


Lesson 21 Name
Build Confidence

Lesson 21 Data
नियमित अभ्यास से अपने अंदर विश्वास पैदा करें। हर दिन पहले से बेहतर टाइप करने का प्रयास करते रहें और गलतियों से सीखें।

Lesson 22 Name
Improve Rhythm

Lesson 22 Data
टाइप करते समय शब्दों के बीच सही लय बनाए रखें। लगातार समान गति से टाइप करने पर आपकी उंगलियों की गति बेहतर होगी।

Lesson 23 Name
Stay Focused

Lesson 23 Data
अभ्यास के दौरान अपना ध्यान केवल स्क्रीन और टाइप किए जा रहे शब्दों पर रखें। ध्यान भटकने से गलतियाँ बढ़ सकती हैं।

Lesson 24 Name
Finger Discipline

Lesson 24 Data
हर कुंजी के लिए सही उंगली का उपयोग करें। गलत उंगली की आदत बाद में आपकी गति और सटीकता को प्रभावित करेगी।

Lesson 25 Name
Typing Without Looking

Lesson 25 Data
अब कीबोर्ड देखे बिना लगातार टाइप करने का प्रयास करें। अपनी उंगलियों की स्थिति पर भरोसा रखें और स्क्रीन पर ध्यान दें।

Lesson 26 Name
Reduce Errors

Lesson 26 Data
अपनी सामान्य गलतियों को पहचानें और उनका अभ्यास करें। बार-बार सुधार करने से वही गलतियाँ धीरे-धीरे कम होने लगेंगी।

Lesson 27 Name
Steady Practice

Lesson 27 Data
अभ्यास के दौरान जल्दबाजी न करें। अपनी गति को स्थिर रखें और प्रत्येक शब्द को सही तरीके से टाइप करने पर ध्यान दें।

Lesson 28 Name
Hand Coordination

Lesson 28 Data
दोनों हाथों को समान रूप से काम करने दें। सही तालमेल से टाइपिंग अधिक सहज और लंबे समय तक आरामदायक बनी रहेगी।

Lesson 29 Name
Improve Accuracy

Lesson 29 Data
आज अपना ध्यान केवल सटीकता पर रखें। धीरे टाइप करें लेकिन प्रत्येक अक्षर और शब्द को सही लिखने का प्रयास करें।

Lesson 30 Name
Speed Practice

Lesson 30 Data
अब अपनी सामान्य गति से थोड़ा तेज टाइप करने का प्रयास करें। गलतियाँ बढ़ने लगें तो गति कम करके नियंत्रण बनाए रखें।

Lesson 31 Name
Continuous Typing

Lesson 31 Data
पूरे अभ्यास के दौरान अनावश्यक रुकावट से बचें। शब्दों को लगातार टाइप करते रहें और अपनी लय को बनाए रखें।

Lesson 32 Name
Typing Flow

Lesson 32 Data
हर शब्द को अगले शब्द से जोड़कर टाइप करें। लगातार प्रवाह बनाए रखने से आपकी टाइपिंग अधिक स्वाभाविक और तेज होगी।

Lesson 33 Name
Accuracy Challenge

Lesson 33 Data
इस अभ्यास में अपनी सटीकता को चुनौती दें। ध्यानपूर्वक टाइप करें और कोशिश करें कि एक भी अनावश्यक गलती न हो।

Lesson 34 Name
Speed Challenge

Lesson 34 Data
अब अपनी पिछली गति से थोड़ा बेहतर प्रदर्शन करने का प्रयास करें। तेज टाइप करते समय सही उंगली और लय बनाए रखें।

Lesson 35 Name
Full Keyboard Review

Lesson 35 Data
अब तक सीखी गई सभी कुंजियों का एक साथ अभ्यास करें। कमजोर कुंजियों पर विशेष ध्यान दें और अपनी गलतियाँ सुधारें।

Lesson 36 Name
Final Practice

Lesson 36 Data
अंतिम अभ्यास में अपनी पूरी क्षमता का उपयोग करें। सही मुद्रा रखें, स्क्रीन देखें और बिना रुके लगातार टाइप करते रहें।

Lesson 37 Name
Final Challenge

Lesson 37 Data
यह अभ्यास आपकी गति और सटीकता दोनों की परीक्षा लेगा। आत्मविश्वास रखें और बिना घबराए पूरे पाठ को ध्यान से टाइप करें।

Lesson 38 Name
Basic Level Mastery

Lesson 38 Data
आपने बेसिक लेवल का पूरा अभ्यास कर लिया है। अपनी प्रगति पर गर्व करें और अगले स्तर के लिए नियमित अभ्यास जारी रखें।
